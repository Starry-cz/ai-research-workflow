## 共同要求

- 先使用冻结模型/API、小型公开数据和可复现评测建立零训练 baseline。
- 默认目标为 CPU、免费 Colab、单张 8–16 GB GPU 或可封顶的小额 API 预算。
- 记录模型/接口版本、prompt、数据边界、成本、时延、失败类型与调用日期。
- 任何 LLM/VLM judge 都要用人工小集校准，不能作为唯一评分者。
- 只选与研究问题直接相关的框架和 benchmark，不以总榜或 Star 决定方案。

## LLM 评测与高效适配

**适用问题**：模型是否正确、稳定、校准、可拒答；prompt、量化或 LoRA 是否在同预算下有效。

**最低比较**：direct/few-shot baseline 与 prompt、解码、量化或 PEFT 中一种受控干预。

**必须评测**：任务正确性、格式、校准、稳定性、鲁棒性、拒答、成本、时延和错误类别。

**必须记录**：模型快照/API 日期、system prompt、few-shot 样例、采样参数、量化/适配配置、重复运行。

**停止条件**：公开 benchmark 与真实任务不匹配；judge 未校准；candidate 与 baseline 预算不公平。

## RAG 与知识增强

**适用问题**：答案依赖外部资料、时效知识、领域语料或可核验引用。

**最低比较**：无检索与 BM25；需要时再增加 dense、hybrid 或 rerank 中一种。

**必须评测**：Recall@k/MRR/nDCG 中适用指标、答案正确性、引用支持、拒答、成本和时延。

**错误分类**：解析、切块、召回、排序、上下文选择、生成、引用。

**测试集**：包含可回答、不可回答、歧义、过时、多跳、长文档和对抗样例。

**停止条件**：语料权利不清；检索失败与生成失败混在一起；只使用单一 LLM judge 分数。

## Agent、工具调用与 MCP

**适用问题**：任务需要规划、多步动作、工具或环境交互；固定 workflow 无法完成。

**最低比较**：固定 workflow 或非 Agent baseline 与 sandbox 中的 Agent。

**必须定义**：任务、工具 schema、参数、权限、状态、终止条件、超时、重试和人工批准点。

**必须评测**：最终结果、工具选择/参数、轨迹、稳定性、成本、时延与安全失败。

**故障注入**：超时、断网、脏数据、权限拒绝、部分工具失败和 prompt injection。

**停止条件**：没有确定性 simulator；测试会触达真实高风险系统；工具调用不可重放或可能无限循环。

## 多模态理解与评测

**适用问题**：关键证据来自图像、图表、论文页面、音频或视频，而非纯文本。

**最低比较**：text-only/单模态 baseline 与冻结多模态模型/API。

**必须评测**：任务正确性、模态依赖、幻觉、校准、鲁棒性、子组结果、成本和时延。

**错误分类**：感知/OCR/ASR、对齐、融合、推理、生成和评测器。

**必须实验**：模态消融与受控扰动，排除模型只靠文字捷径或数据偏差答对。

**停止条件**：人物数据缺少许可/同意；主体切分泄漏；只展示挑选的成功案例；judge 未人工校准。
