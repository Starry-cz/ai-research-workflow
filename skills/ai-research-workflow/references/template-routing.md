# 现有模板路由

首次使用优先复制 `assets/core-templates.md` 中对应的轻量核心模板。已有项目存在等价 README、Issue、tracker 或实验表时，直接映射并补缺。

在本仓库内开发时，以下详细模板作为 standard/advanced 版本；Skill 被独立安装、无法访问这些路径时，继续使用六张轻量核心模板，不要虚构缺失文件。

| 当前任务 | 首选模板 |
| --- | --- |
| 判断是否具备起步条件 | `templates/00-readiness-checklist.md` |
| 定义问题、方向或导师任务 | `templates/01-research-brief.md` |
| 精读一篇核心论文 | `templates/02-paper-reading-card.md` |
| 复现论文代码 | `templates/03-reproduction-plan.md` |
| 运行受控实验 | `templates/04-experiment-card.md` |
| 每周决定继续、停止或求助 | `templates/05-weekly-review.md` |
| 把今天的任务缩到可验收 | `templates/06-daily-task-card.md` |
| 建立可复查的文献检索 | `templates/07-literature-search-log.md` |
| 迁移服务器、数据或算力 | `templates/08-compute-data-environment-checklist.md` |
| 投稿、rebuttal、转投或归档 | `templates/09-submission-review-archive.md` |
| 调试、求助或向上游反馈 | `templates/10-debug-help-request.md` |
| 筛选首篇 baseline 或判断能否改进 | `templates/11-first-baseline-gate.md` |
| 数学公式阻塞当前任务 | `templates/12-math-concept-card.md` |
| 数据进入项目 | `templates/13-dataset-card.md` |
| 正式比较前冻结评价 | `templates/14-evaluation-spec.md` |
| 结果进入组会、决策或写作 | `templates/15-result-claim-audit.md` |
| 关键运行交给他人复查 | `templates/16-run-handoff.md` |

不要按编号顺序填写，不要一次复制全部模板。同一事实只保留一个主要来源：配置链接实际 config，指标链接冻结结果或 tracker，其他卡片只记录身份与路径。
