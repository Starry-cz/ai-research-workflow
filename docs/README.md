# 指南索引

这里保存科研工作流的执行细节。不要按文件名逐篇阅读；先选择当前状态，只打开一份主指南，遇到对应事件再进入专项检查。

## 30 秒选择

| 当前状态 | 先打开 |
| --- | --- |
| 不会终端、Git 或 Python 环境 | [L0 工具链起步](L0_TOOLCHAIN_START.md) |
| 能运行 Notebook，但不理解训练、验证与测试 | [第一个机器学习闭环](ML_FIRST_LOOP.md) |
| 有基础但不知道选什么方向 | [方向选择决策树](DIRECTION_FIRST_CHOICE.md) |
| 已有题目，准备执行完整项目 | [核心科研工作流](CORE_RESEARCH_WORKFLOW.md) |
| 已经卡在数据、评价或结果解释 | 直接进入下方对应的事件指南 |

## 事件触发指南

| 指南 | 何时使用、前置条件与最低产物 |
| --- | --- |
| [论文发现与原文回溯](PAPER_DISCOVERY_FIRST_PASS.md) | **触发**：开始新方向、拿到种子论文或准备筛选首篇 baseline。<br>**产物**：查询记录，以及“发现入口—书目身份—原文版本—官方代码”回溯链。 |
| [真实代码库最小接入](ADOPT_WORKFLOW_IN_EXISTING_PROJECT.md) | **触发**：拿到导师项目、实验室仓库、论文官方代码或单个 Notebook。<br>**产物**：现有记录映射、唯一来源、第一条 `commit—config—run_id—结果—决定` 证据链和接入状态。 |
| [baseline 稳定化与首次改进](BASELINE_STABILIZATION_GATE.md) | **触发**：完成复现，准备改模型、损失、数据或训练流程。<br>**产物**：论文目标、本地 baseline、复现差距、规模升级证据与四选一门控决定。 |
| [第一次安全修改论文代码](SAFE_FIRST_CODE_CHANGE.md) | **触发**：准备修环境、修 baseline、重构、加观测或修改研究方法。<br>**产物**：修改前快照、改动类别、最小 patch、前后检查证据、diff 审查和准入状态。 |
| [运行交接与冷启动复查](RUN_HANDOFF_REPLAY.md) | **触发**：关键运行进入组会、图表、服务器迁移、项目暂停或负责人变更。<br>**产物**：唯一交接入口、H0–H3 深度、资产权限、指标重算、冷启动记录和交接状态。 |
| [实验产物保留、归档与安全清理](EXPERIMENT_ARTIFACT_LIFECYCLE.md) | **触发**：大量 checkpoint / 日志产生、存储告警、平台 TTL、项目暂停、投稿或结题。<br>**产物**：产物分类、负责人、复查日、主张引用、清理门与生命周期决定。 |
| [按任务补数学](MATH_ON_DEMAND.md) | **触发**：某个公式或概念正在阻塞论文、代码或实验。<br>**产物**：符号、shape、假设、玩具数值和代码映射。 |
| [数据集审计](DATASET_FIRST_AUDIT.md) | **触发**：数据准备进入项目或划分发生变化。<br>**产物**：来源、权利、版本、schema、split、泄漏和准入决定。 |
| [评价协议](EVALUATION_FIRST_SPEC.md) | **触发**：准备正式比较模型、方法或系统。<br>**产物**：冻结的主指标、实现、聚合、统计单位和决策门槛。 |
| [公平调参与搜索预算](FAIR_TUNING_BUDGET.md) | **触发**：baseline 或候选需要选择超参数、运行 sweep、使用 pilot 筛配置。<br>**产物**：变量分类、各方法搜索空间与预算、完整 trial 台账、冻结配置和公平性决定。 |
| [结果到主张](RESULT_TO_CLAIM.md) | **触发**：实验完成，准备画图、写报告或论文结论。<br>**产物**：完整性、错误、反例、替代解释、图表来源和主张状态。 |
| [渐进式项目结构](PROJECT_STRUCTURE.md) | **触发**：数据、实验、论文或协作规模增长。<br>**产物**：从七项最小骨架升级的可查找项目结构。 |

## 推荐顺序

完全零基础：

```text
L0 工具链 → 第一个 ML 闭环 → 方向选择 → 核心科研工作流
```

已经有导师任务或 baseline：

```text
方向选择中的“导师 / 团队任务”分支 → 核心科研工作流
```

事件指南只在触发时插入主路径，不需要提前完成。

## 与模板的关系

- `docs/` 解释为什么做、何时做和如何验收；
- [`templates/`](../templates/README.md) 保存需要填写的记录；
- [`examples/first-workflow-drill/`](../examples/first-workflow-drill/README.md) 展示一条已实际运行的最小证据链；
- 根目录 [`README.md`](../README.md) 负责定位、分流、路线和任务导航。

如果实验室已有等价指南或台账，复用现有体系并补缺，不为匹配本仓库维护第二套文档。
