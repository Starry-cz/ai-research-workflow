## 3. 必须通过的准入门控

对主候选逐项判断 `PASS / REFINE / STOP`，并附证据位置。

- [ ] **目标可定位**：不是“复现这篇论文”，而是能指出目标表格、图、指标、数据集和对应主张。
- [ ] **来源可核验**：论文版本、官方仓库关系和代码 commit 已锁定。
- [ ] **数据可使用**：数据确实可获得，版本、划分、预处理和许可证满足当前用途。
- [ ] **环境可建立**：依赖、框架、运行时和硬件要求足够明确，可在干净环境安装并 import。
- [ ] **训练可执行**：若目标是完整训练复现，存在训练入口、配置和必要初始化权重。
- [ ] **评测可执行**：存在指标定义、评价脚本和能够对应目标结果的命令。
- [ ] **资源可承受**：根据短试跑或可信报告估算后，显存、时间、存储、下载和费用不超限。
- [ ] **成功可判定**：已经预设容差、差异说明方式和“完全 / 部分 / 未复现”判定。
- [ ] **失败可退出**：每个未决问题都有负责人、截止时间、停止条件和备选候选。

出现以下情况时，首篇 baseline 默认 `STOP`：数据无权使用；目标结果无法定位；完整训练目标没有训练或评测入口；资源明显超过预算且没有合法的缩小协议；最小链路多次失败但无法形成可检验原因。若导师决定继续，应记录理由、额外支持和调整后的交付目标。

## 4. 低成本预检记录

### P0 静态资料检查

- 检查日期：

- 目标结果对应的命令是否存在：

- 决定：继续 / 限时补证据 / 停止

### P1 干净安装与 import

- 环境路径与环境文件：
- 完整安装命令：
- import 或启动命令：
- 实际结果与首个关键错误：
- 未解释的人工或 AI 修改：
- 决定：继续 / 回退 / 停止

### P2 官方权重或最小公开样例

- 运行命令：
- 输入、输出和产物路径：
- 官方预期与实际观察：
- 是否只验证了推理链路：
- 决定：继续 / 回退 / 停止

### P3 短训练与资源外推

- 数据规模、batch、step / epoch：
- 峰值显存、吞吐、运行时间和输出体积：
- 预计完整训练时间、存储和费用：

- 估算误差和未覆盖成本：
- 决定：继续 / 缩小目标 / 停止

### P4 本地 baseline 稳定化

- 论文目标值与对应协议：
- 未加入研究改动的本地 baseline commit：
- 本地 baseline 的全部 run IDs：
- 中心趋势、离散与异常运行：
- 训练 / 验证曲线和 checkpoint 选择：
- 与论文目标的差距：
- 数据 / 代码 / 环境 / 预算 / 评价 / 随机性排查证据：
- 未解释残差及其是否可能与候选改动交互：
- pilot 到代表性规模的复查结果：保持 / 减弱 / 反转 / 未检查
- 稳定化决定：READY_FOR_CHANGE / REPRODUCTION_ONLY / COMPARATOR_ONLY / REPLACE_BASELINE
- 决定依据与允许主张：

只有 `READY_FOR_CHANGE` 可以把该实现作为首次方法改进的主 baseline。其他状态的处理规则见[从 baseline 复现到首次改进](../docs/BASELINE_STABILIZATION_GATE.md)。

## 5. 分层里程碑与成功标准

- **M0 目标冻结**：论文、代码、数据、目标结果和容差均已记录。
- **M1 官方评测**：官方权重或官方输出完成评测，只说明推理与评价链路可用。
- **M2 短训练**：最小训练、保存和恢复通过，只说明训练链路可用。
- **M3 完整复现**：完整协议达到预设容差，或差异有可核验证据并被标记为部分 / 未复现。

- 本项目计划达到的最高里程碑：
- 每个里程碑的产物路径与验收人：
- 预设复现容差及理由：
- 允许的协议差异：
- 不允许悄悄改变的内容：

M1 不能替代 M2 或 M3，M2 也不能被写成完整复现。若只计划学习代码并停在 M1 或 M2，应在项目标题和总结中如实标注。
