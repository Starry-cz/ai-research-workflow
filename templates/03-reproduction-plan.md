## 5. 复现关卡

### A. 环境与官方权重

- [ ] 锁定 commit 和依赖
- [ ] 记录操作系统、Python、框架、加速器、驱动和运行时版本
- [ ] 在干净环境中按环境文件完成一次安装
- [ ] 已完整阅读项目 README、安装说明和数据目录要求
- [ ] 官方权重完成推理或评测
- [ ] 一个 batch 或小数据子集完成冒烟测试
- [ ] 指标、样例输出与官方说明基本一致

### B. 结构与 shape

- [ ] 随机张量或极小数据跑通 forward
- [ ] 关键层 shape 与论文公式、图和代码一致
- [ ] 论文与代码差异已记录

### C. 梯度与单批次

- [ ] 固定随机种子
- [ ] 关闭不必要的增强和正则化
- [ ] 单批次 loss 明显下降
- [ ] 关键参数有梯度，无 NaN / Inf

### D. 完整训练

- [ ] 保存命令、配置、日志和硬件信息
- [ ] 短试跑已生成 checkpoint，并完成主动中断后的恢复测试
- [ ] checkpoint 包含续训所需状态，且重要副本不只存在于临时实例
- [ ] 根据实测吞吐重新估算总时长、存储和费用，未超过停止阈值
- [ ] 验证集选择规则预先确定
- [ ] 完成目标训练轮次与评测

### E. 结果判定

- [ ] 与论文设置差异已列明
- [ ] 指标差异有证据支持的解释
- [ ] 状态标记为完全复现 / 部分复现 / 未复现
