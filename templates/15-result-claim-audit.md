# 结果—主张审计卡

实验完成后、制作论文图表或写结论前填写。不要覆盖原始预测、日志或旧版审计。

## 2. 结果完整性

- [ ] 所有计划运行均有状态，失败和排除项没有消失
- [ ] 排除规则与评价协议一致
- [ ] baseline 与候选比较公平，差异已披露
- [ ] baseline 与候选的搜索空间、trial 数和计算预算已披露
- [ ] 全部调参尝试均有状态，候选没有获得未记录的额外搜索
- [ ] 最好配置来自预先声明的验证规则，而非测试集或事后挑选
- [ ] best-of-N 的 N、失败、剪枝和人工介入已经计入解释
- [ ] 汇总数字可以从冻结输入重算
- [ ] 正文、图表和日志使用同一版本
- [ ] 测试结果没有触发静默调参或选择

- 未通过项及影响：
- 当前结果可用于：正式证据 / 初步观察 / 调试线索 / 作废

## 3. 证据等级与共享边界

- 本次要输出的对象：单条消息 / 组会页 / 结果包 / 项目决定 / 公开页面 / 论文图表或主张
- 目标受众：个人 / 团队 / 指定合作者 / 公开读者 / 投稿评审
- 验证等级：V0 `UNVERIFIED_SIGNAL` / V1 `TRACEABLE_OBSERVATION` / V2 `AUDITABLE_RESULT` / V3 `DECISION_EVIDENCE` / V4 `MANUSCRIPT_CLAIM_READY`
- 等级依据与未通过的下一等级条件：
- 共享等级：S0 `PRIVATE_RESTRICTED` / S1 `TEAM_ONLY` / S2 `CONTROLLED_COLLABORATOR` / S3 `PUBLIC_VIEWABLE`
- 授权人、确认记录、匿名要求、许可证或数据条款：
- 允许共享的文件与受众：
- 必须删除、替换或保持私密的内容：
- 当前允许表述：
- 当前禁止表述：
- 用途状态：HOLD_PRIVATE / INTERNAL_DEBUG / MEETING_PRELIMINARY / SHAREABLE_ARTIFACT_ONLY / DECISION_READY / MANUSCRIPT_CLAIM_READY
- 升级所需新证据：
- 降级、失效或重开触发：

验证等级与共享等级必须分别判断。公开可见不等于可自由复用，artifact 可运行不等于主张成立；具体规则见[实验结果证据等级与表达边界](../docs/EVIDENCE_READINESS_AND_SHARING.md)。
