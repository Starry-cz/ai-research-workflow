# 算力、数据与环境迁移清单

用于实验室服务器、云 GPU、临时 Notebook 或跨机器迁移。先完成短试跑和恢复测试，再开始长时间训练。

## 1. 任务与资源边界

- 项目 / baseline：
- 代码仓库 / commit：
- 运行目标：评测 / 冒烟测试 / 完整训练 / 消融 / 其他
- 选择本地、实验室服务器或云端的理由：
- 预计开始与结束时间：
- 最晚停止日期：
- 资源所有者 / 配额负责人：
- 获准设备、时长、费用与确认记录：
- 是否允许将代码、数据、日志或结果传给该平台：

资源清单：

- 加速器型号与数量：
- 单卡显存与实测峰值显存：
- CPU 核数与内存：
- 训练精度：FP32 / TF32 / BF16 / FP16 / 其他
- 原始数据体积：
- 处理后数据与缓存体积：
- checkpoint、日志和结果预留空间：
- 预计总步数或 epoch：

## 2. 数据与传输

- 数据来源与许可证：
- 数据版本、发布日期或快照标识：
- 下载命令或获取步骤：
- 预计下载量与解压后体积：
- 校验算法与校验值：
- 失败后是否支持继续下载：
- 权威备用来源：

路径约定：

- `DATA_ROOT`：
- `CACHE_ROOT`：
- `OUTPUT_ROOT`：
- 路径是否通过配置或环境变量传入：是 / 否
- 是否存在写死的个人绝对路径：是 / 否

不要把未经授权的数据上传到第三方平台。镜像、网盘或他人转存只能作为传输方式，数据版本、许可证和完整性仍需回到权威来源核对。

## 3. 环境重建

- 操作系统与架构：
- Python 版本：
- 深度学习框架版本：
- 加速器驱动与运行时版本：
- 环境文件或锁定文件：
- 安装命令：
- import / 版本检查命令：
- 官方评测或最小冒烟命令：

干净环境验收：

- [ ] 从新环境按文档完成安装
- [ ] 没有依赖当前机器中未声明的全局包
- [ ] 关键包、驱动和框架版本已保存到日志
- [ ] 同一条冒烟命令能够成功退出
- [ ] 平台差异和无法固定的部分已记录

锁定依赖能减少版本漂移，但不能保证不同操作系统、硬件、驱动或框架版本得到完全相同结果。

- Git 管理的内容：
- 外部存储的数据与大文件：

- 实例释放后会删除的目录：

安全检查：

- [ ] `.gitignore` 已排除原始数据、缓存、checkpoint、`.env` 和密钥
- [ ] 仓库只保留 `.env.example` 或变量说明，不含真实凭证
- [ ] 数据、模型和代码许可证允许当前用途
- [ ] 平台账户、共享目录和文件权限符合课题组要求
- [ ] 技术访问、任务授权与数据使用范围均已确认，未把账号可登录视为允许上传

## 5. 短试跑与恢复测试

按顺序记录，不跳级：

- [ ] 完成 import 与设备识别
- [ ] 完成极小数据或一个 batch 的前向
- [ ] 完成一个 batch 的反向与参数更新
- [ ] 完成短试跑并保存 checkpoint
- [ ] 主动终止进程
- [ ] 从 checkpoint 恢复到预期 epoch / global step
- [ ] 恢复后继续训练，并确认指标与学习率状态合理
- [ ] 成功导出日志、配置、指标和 checkpoint

恢复证据：

- 保存命令与日志：
- 恢复命令与日志：
- 中断前 step：
- 恢复后首个 step：
- checkpoint 包含的状态：
- 尚未恢复的状态及影响：

## 6. 预算与停止规则

- 价格或配额核验时间：
- 计算计费方式：
- 存储与网络计费方式：
- 短试跑时长与完成进度：
- 实测吞吐或每 step 时间：
- 预计总时长：
- 预计总费用：
- 最大可接受费用：
- 最大可接受空闲时长：
- checkpoint 间隔与最多可接受丢失时间：
- 自动或人工停止条件：

确认平台对“停止、关机、释放、保留磁盘和删除实例”的定义。关闭训练进程不一定停止计费，停止实例也不一定保留临时磁盘。

## 7. 完整运行与离场检查

运行期间：

- [ ] 记录启动命令、配置、commit、数据版本、随机种子和硬件
- [ ] 监控 loss、指标、GPU 利用率、显存、I/O、磁盘和异常
- [ ] checkpoint 已按计划写入持久化位置
- [ ] 超过预算、磁盘水位或异常阈值时停止并记录

释放算力前：

- [ ] 日志、配置、指标、图表和必要权重已导出
- [ ] 关键文件已记录大小与校验值
- [ ] 在归档位置抽查文件可打开或 checkpoint 可加载
- [ ] 临时缓存已按数据政策处理
- [ ] 已确认实例、磁盘和其他计费资源的最终状态

## 8. 最终迁移验收

- [ ] 另一台干净机器能够按环境说明完成安装
- [ ] 数据能够按清单定位并通过校验
- [ ] 冒烟命令无需修改研究代码即可运行
- [ ] checkpoint 能恢复到预期训练状态
- [ ] 结果能定位到代码 commit、配置、数据版本和运行日志
- [ ] 实际时长与费用已回填，偏差原因已解释
