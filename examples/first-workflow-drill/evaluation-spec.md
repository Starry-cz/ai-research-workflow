# 教学演练评价协议

## 1. 主张与决策

- 实验 ID：`EXP-DEMO-001`
- 主要主张：两份预先写定的配置可以在相同教学协议下运行、完整汇总并追溯到产物
- 本轮决策：工作流证据完整则 `PROCEED` 到真实 baseline；不选择科研方法
- 评价对象：固定合成二分类数据上的最后一轮模型
- baseline / candidate：学习率 `0.1` / `0.4`，其他配置一致
- 协议性质：确认工作流，不确认方法优越性

## 2. 数据与权限

- 数据集卡：[dataset-card.md](dataset-card.md)
- 评价样本：固定 validation 30 条、test 30 条
- 样本级指标单位：单条合成样本
- 跨运行汇总单位：一次独立参数初始化 seed
- 测试集权限：脚本会在每次训练后计算；本演练不根据它继续调参或筛选 seed

## 3. 指标实现

| 指标 | 冻结定义与用途 |
| --- | --- |
| 测试 accuracy | 主报告指标；正确预测数除以 30，阈值固定为 `0.5`，越高越好。 |
| 验证 accuracy | 辅助指标；检查两组在同一 validation split 上的表现，不用于继续搜索。 |
| 交叉熵 loss | 诊断概率预测；代码将概率截断到 `[1e-12, 1-1e-12]` 后取平均，越低越好。 |

- 实现位置：`train.py::evaluate()` 与 `train.py::summarize()`
- 预测规则：`probability >= 0.5` 为 label `1`
- 空集合 / 缺失预测：脚本当前不会产生；若运行报错，该 run 标为失败而不是从汇总中静默删除
- 已知样例：30 条全预测正确时 accuracy 为 `1.0`
- 重算入口：各 `results/*/metrics.json` 保存每个 seed 的 validation / test 指标；当前示例未保存逐样本预测，这是迁移到真实研究前需要补齐的边界

## 4. 重复运行与不确定性

- 预先计划 seed：`17, 29, 43, 71, 97`
- 变异来源：仅参数初始化；数据和划分固定
- 汇总：五次运行的均值、总体标准差、最小值和最大值
- `population_std` 含义：描述这五个预先计划运行的离散程度，不是标准误或置信区间
- 推断统计：不进行
- 实际意义门槛：不设置；本演练不据数值差异声称方法优越
- 排除规则：不排除已计划运行；实现失败保留记录，修复后使用新 ID

## 5. 冻结与结论边界

- 指标、阈值、seed、epoch 和汇总在查看记录结果前写定
- 不能根据测试结果增加 seed、改阈值、换数据划分或只保留最好运行
- 支持的结论：仓库演练能够保存两组配置的可审计结果和初始化波动
- 不支持的结论：候选学习率在真实数据、其他模型、其他预算或统计总体上更优
- 决策：全部计划运行与证据文件存在时 `PROCEED` 到真实 baseline
