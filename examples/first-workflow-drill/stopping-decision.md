# 教学演练停止与转向决定

本页只审计仓库内“第一次可审计实验演练”。它使用已经冻结和实际运行的产物，不新增虚构负结果，也不把合成任务的数值解释成真实方法贡献。

## 1. 当前研究单元

- 单元：教学演练中的 baseline / candidate 单变量比较；
- 问题：零基础读者能否按固定配置、五个预先声明 seed 和统一评价规则，完成一条可追溯、可重算的实验链？
- 非目标：寻找该合成任务的最佳学习率、证明 `0.4` 普遍优于 `0.1`，或形成算法创新；
- 预算边界：只运行既定 debug、baseline 和 candidate 配置，不开展额外学习率 sweep；
- 证据入口：[实验卡](experiment-card.md)、[结果—主张审计](result-claim-audit.md)、[证据等级判断](evidence-readiness.md)与 `results/*-recorded/`。

## 2. 尝试台账

| 尝试 | 新增的可区分信息 | 结果类别 | 证据与决定影响 |
| --- | --- | --- | --- |
| debug 固定 seed | 训练、评价和四类文件能否正确生成 | `POSITIVE_BOUNDED` | `debug-recorded/` 完整；允许进入预设比较，但不进入方法结论。 |
| baseline 五个 seed | 对照配置的完整运行与波动 | `POSITIVE_BOUNDED` | 五项运行均 completed，测试 accuracy 均值可重算为 `0.840000`。 |
| candidate 五个 seed | 唯一主要变量变化下能否完成公平教学比较 | `POSITIVE_BOUNDED` | 五项运行均 completed，均值可重算为 `0.966667`；只支持协议内教学观察。 |
| H2 冷启动复跑与验收 | 另一环境能否按入口重建最小链路和重算指标 | `POSITIVE_BOUNDED` | 验收通过；结果达到 V2，但不升级成真实项目的 V3 / V4。 |

这里没有 `VALID_NEGATIVE`。如果某组协议有效但未达到预设门槛，它才会被归为有效负结果；命令报错、输出缺失或错误数据划分应归为 `INVALID_RUN`，不能混写成“候选无效”。

## 3. 五个停止门

- **协议有效**：配置、命令、环境、日志、全部 seed 和汇总重算均可定位；
- **下一步区分力**：再试一个学习率只会扩大事后搜索，不回答本教学单元的新问题；
- **边际信息**：当前目标是验证证据链，目标已经达到，继续优化小数没有新的科研信息；
- **预算闭环**：原计划运行、验收和归档均完成，不应把剩余时间自动转成额外 sweep；
- **权限与风险**：演练使用脚本生成数据并公开展示，但仓库尚未确认许可证，公开可见不等于任意复用。

## 4. 最终决定

- 顶层决定：**`STOP`**；
- 原因码：**`ANSWERED`**；
- 对象：停止当前合成教学实验的继续调参，而不是停止学习或真实科研项目；
- 当前最强结论：在仓库记录的固定教学协议下，完整实验链可以运行、追踪和重算；
- 禁止结论：更高学习率普遍更优、该设置适用于真实任务、当前结果构成论文贡献；
- 后续转移：进入首篇真实 baseline 的准入、复现和评价协议，而不是继续优化玩具任务；
- 重开触发：`train.py`、数据生成、配置、评价规则、验收脚本或记录结果发生变化，需要重新确认教学链路；
- 非重开依据：为了得到更高 accuracy、尝试更多 seed 或补一张更漂亮的图。

`STOP + ANSWERED` 与主工作流中的 `PROCEED` 不矛盾：前者关闭已经回答的当前实验单元，后者批准进入下一里程碑。停止对象必须写清，避免把“停止一个实验族”误读成“放弃整个方向”。

## 5. 可用于周会的一句话

> 当前教学实验的协议与全部计划运行已完成，证据链达到 V2；继续搜索学习率不会回答新的教学问题，因此以 `STOP + ANSWERED` 关闭该实验族，并把下一项资源投入真实 baseline 接入。
