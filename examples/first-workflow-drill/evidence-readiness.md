# 教学演练证据等级与共享判断

本页只对仓库内“第一次可审计实验演练”的现有产物评级。它演示如何把证据成熟度与共享权限分开，不把公开可见的教学结果升级成科研方法主张。

## 1. 本次输出对象

- 输出：baseline 与 candidate 的记录结果、验收结果及一句教学说明；
- 受众：阅读本公开仓库的零基础学习者；
- 证据入口：[实验卡](experiment-card.md)、[结果—主张审计](result-claim-audit.md)、[运行交接](run-handoff.md)和 `results/*-recorded/`；
- 当前用途：展示如何从配置、运行和指标形成可审计教学链路；
- 非目标：证明学习率 `0.4` 是新方法、普遍优于 `0.1`，或对真实任务有效。

## 2. 证据成熟度

### 调试运行

- 等级：**V1 `TRACEABLE_OBSERVATION`**；
- 已有证据：`debug-recorded` 能回到固定配置、命令、环境、日志和单个 seed；
- 未升级原因：它只用于确认链路，epoch 与运行集合不足以进入正式比较；
- 允许表述：“记录的调试命令已生成预期四类产物。”；
- 禁止表述：“调试结果证明模型有效。”

### baseline 与 candidate 比较

- 等级：**V2 `AUDITABLE_RESULT`**；
- 已有证据：两组各五个预先声明 seed 均完成，没有排除项；配置只改变 `experiment_id` 与 `learning_rate`；汇总可由 `verify.py` 重算；冻结产物和 H2 冷启动复跑均有记录；
- 允许表述：“在固定合成数据、80 epoch、五个预先声明 seed 和当前评价规则下，candidate 记录的测试 accuracy 均值为 `0.966667`，baseline 为 `0.840000`；本结果只验证教学比较流程。”；
- 禁止表述：“更高学习率普遍更好，已经形成新的训练方法。”

没有升级到 V3，原因包括：没有真实研究问题、代表性数据、论文 baseline、实际意义门槛、逐样本错误分析或真实任务资源权衡；维护者完成冷启动核验只能证明入口可执行，不等于独立团队确认科研结论。

没有升级到 V4，原因包括：`CLAIM-DEMO-002` 已被拒绝，限定观察 `CLAIM-DEMO-003` 也只允许进入实验说明；本例不产生论文贡献。

## 3. 共享权限

- 等级：**S3 `PUBLIC_VIEWABLE`**；
- 依据：输入由脚本生成，不包含外部个人数据、受限数据、密钥、匿名稿件或第三方模型；相关文件已位于公开仓库；
- 限制：仓库尚未确认许可证，因此“公开可见”不能表述成“已获开放许可证、可任意复制或再分发”；
- 允许内容：配置、脚本、记录产物、限定教学说明和验收命令；
- 禁止内容：把公开页面当成同行评审、独立复现或方法有效性的证明。

## 4. 本次用途状态

- 最终状态：**`SHAREABLE_ARTIFACT_ONLY`**；
- 为什么不是 `MEETING_PRELIMINARY`：本页不是待确认的组会汇报，而是已经冻结并可重算的教学 artifact；
- 为什么不是 `DECISION_READY`：它只支持“进入真实 baseline”的教学决定，不支持真实研究路线或资源投入决定；
- 为什么不是 `MANUSCRIPT_CLAIM_READY`：没有任何真实方法主张达到 V4；
- 降级触发：`train.py`、`verify.py`、配置、记录结果、数据生成、评价规则或 README 数字发生变化后，先降到 V1，重新运行验收与证据评级。

## 5. 可直接用于 README 的一句话

> 这组公开记录结果达到 V2：全部计划运行可追溯、可重算，并可作为教学 artifact 查看；它不支持任何真实任务中的方法优越性主张。

这个例子说明：一个结果可以同时“公开可见、运行完整、仍然不能写成科研贡献”。
