# EXP-DEMO-001 实验卡

## 1. 实验问题

- 运行模式：confirmatory workflow drill（确认工作流，不确认科研主张）
- 研究假设：在相同教学任务和预算下，只改变学习率会产生可记录的训练结果差异。
- 本轮唯一主要问题：两份预先写定的配置能否被公平执行、完整汇总并追溯到运行产物？
- 可检验预测：两组都会生成五个已声明 seed 的结果、环境记录和汇总值。
- 替代解释：任何数值差异都可能只属于该合成数据、训练轮数或初始化集合。

## 2. 实验设计

- 评价协议：[evaluation-spec.md](evaluation-spec.md)
- baseline：`configs/baseline.json`，学习率 0.1。
- 唯一主要改动：候选配置的学习率改为 0.4。
- 科学变量：无；本例不声称提出研究变量。
- 练习变量：学习率。
- 固定变量：脚本、数据生成与划分、epoch、模型、损失、评价和 seed 集合。
- 对照组：baseline 与 candidate。
- 数据与划分：脚本内固定生成 180 条合成样本；120 / 30 / 30 固定切分。
- 主指标与辅助指标：测试准确率；验证准确率与交叉熵损失。
- 统计单位与实际意义门槛：每个 seed 是一次独立初始化运行；本演练不设置方法优越性的实际意义门槛，也不做推断统计。
- 预先计划的 run_id 与随机种子：两组均为 17、29、43、71、97；五次是本演练的选择，不是通用规范。
- 调参预算与各组公平性：两组均训练 80 epoch，不继续搜索学习率。
- checkpoint / 模型选择规则：不选择 checkpoint；使用每次运行最后一个 epoch。
- 结果汇总方式与波动来源：报告全部运行的均值、总体标准差、最小值和最大值；波动来自不同初始化。
- 预算：CPU、小于一分钟；实际时间受设备影响。
- 复查触发器：两组全部计划运行完成，或任何运行报错、配置不一致、产物缺失时立即复查。
- 结果分类判据：链路失效为 `INVALID_RUN`；全部计划运行完整且教学预测达到为 `POSITIVE_BOUNDED`；本例不以 accuracy 涨点定义科研正 / 负结果。
- 停止条件：教学工作流问题回答后以 `STOP + ANSWERED` 关闭本实验族；出现失效则保留错误并 `REFINE + INVALID_PROTOCOL`。
- 重开触发器：脚本、数据生成、配置、评价、验收或记录产物发生变化。
- 失败判定：脚本异常、计划 seed 缺失、配置不一致或产物无法回到命令。
- 运行排除规则：不排除任何已计划运行；实现错误导致的运行保留记录，修复后创建新 ID。

## 3. 版本与环境

## 5. 结果

- 主结果：baseline 的测试准确率均值为 0.840000，总体标准差为 0.013333；candidate 为 0.966667 和 0.000000。原始精度与全部小数位以 `results/*/metrics.json` 为准。
- 全部计划运行及状态：两组各 5 次，共 10 次，全部为 `completed`；没有删除或排除运行。
- 中心趋势、离散程度或区间：每组均报告均值、总体标准差、最小值和最大值，见各自 `summary` 字段。
- 波动来源与计算方式：不同初始化；使用总体标准差，只描述本演练中的五次计划运行。
- 训练与验证曲线：本演练未保存逐 epoch 曲线，这是迁移到真实项目时需要补充的边界。
- 运行时间、显存和吞吐量：未作为比较指标。
- 失败、中断与排除运行及理由：本次记录中没有失败、中断或排除项。
- 与 baseline 的差异：candidate 在这组固定合成数据和协议下具有更高的验证与测试准确率；该观察不外推到其他数据、模型或训练预算。

## 6. 结论与决策

- 结果—主张审计：[result-claim-audit.md](result-claim-audit.md)
- 假设得到支持 / 部分支持 / 不支持：支持“可公平执行并完整归档两组预先声明配置”的工作流假设；不评价科研方法假设。
- 证据：两组配置快照、环境、日志与指标文件。
- 无法排除的替代解释：合成数据简单、样本少、模型单一、只比较两个学习率。
- 结论适用边界：只说明可审计工作流是否跑通。
- 决策：当前教学实验族为 `STOP + ANSWERED`；主工作流 `PROCEED + NEXT_MILESTONE_READY`，进入有官方代码与评价入口的真实 baseline。
- 依据：继续搜索学习率不会回答新的教学问题，且会把预设比较扩张为事后搜索。
- 保留证据与重开触发器：保留两组配置、日志、环境、全部运行与验收；只有执行链或协议变化时重开。
