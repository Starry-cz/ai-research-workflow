# 练习：从模糊症状找到可安全复用的知识

本练习不会修改代码、删除目录或覆盖结果。请先完成自己的判断，再打开文末答案。预计只需要几分钟。

## 任务情景

你在教学项目中重新运行一条训练命令，终端在训练开始前退出。你记得看到“输出目录非空”和一段 traceback。另一位同学建议：“旧结果没用了，删掉目录，或者加 `--overwrite` 就能继续。”

你当前只被授权读取仓库、查看命令帮助，并在新的临时目录运行；没有权限删除仓库证据或修改脚本。

请判断：应该直接采用同学建议，还是先复用仓库内某条知识？

## 规则

- 不先打开[教学知识索引](knowledge-index.md)或[已填写答案](knowledge-retrieval-result.md)；
- 不删除 `results/*-recorded`，不编辑 `train.py`；
- 不假设 `--overwrite` 存在；
- 搜索结果只产生候选，必须打开来源并核对当前身份；
- 教学干扰项会出现在搜索结果中，但不属于正式知识。

## 第一步：写下原始症状

在自己的临时笔记中写：当前任务、预期、实际、看到的原词、命令、当前目录和允许动作。不要先写猜测的原因。

## 第二步：逐层搜索

在仓库根目录运行下面三类查询；允许根据实际命中调整词语，但要保存原查询：

```bash
git grep -n -E "输出目录|拒绝覆盖"
git grep -n "FileExistsError"
git grep -n -E "prepare_output|overwrite|output-dir" -- examples/first-workflow-drill
```

至少打开两个候选。注意：搜索会命中本练习、正式条目、原始记录和[教学候选夹具](knowledge-retrieval-fixtures.md)。命中练习文本本身不算找到证据。

## 第三步：比较候选

对每个候选回答：

- 它是正式条目、原始来源，还是明确标记的教学夹具？
- 状态是活动、临时、已替代还是退役？
- 症状和发生阶段是否一致？
- 当前脚本、命令帮助和 README 是否支持它？
- 建议动作是否超出当前授权或具有破坏性？
- 哪项证据能排除这个候选？

## 第四步：做最小验证

在演练目录查看帮助：

```bash
python train.py --help
```

然后打开 `train.py` 的 `prepare_output` 和 README 的输出目录说明。你可以在一个新的个人目录运行 debug 配置，但不得为了让旧命令成功而删除记录目录。

## 第五步：提交结果

写下：

- Q0 / Q1 / Q2 查询与候选；
- 保留与排除理由；
- 当前来源和最小验证；
- `APPLY_WITHIN_SCOPE / VERIFY_BEFORE_APPLY / DO_NOT_APPLY / SUPERSEDE_ENTRY / ESCALATE_RESTRICTED` 中的一个决定；
- 实际动作和写回位置。

### 成功标志

- 找到正式条目，但没有把它当作无需核验的答案；
- 明确拒绝不存在、无来源或越权的建议；
- 使用新目录验证，而非删除已有证据；
- 结论只覆盖当前教学脚本和当前症状。

完成后再打开[已填写检索与复用结果](knowledge-retrieval-result.md)。维护者可以运行 `python verify_knowledge_retrieval.py` 检查教学材料与当前脚本是否仍一致；该脚本不能替代真实新手测试。
